# Решение домашнего задания (Вариант б)

Исходные данные:
A = 1 (ИСТИНА)
B = 0 (ЛОЖЬ)
C = 1 (ИСТИНА)

## Ответы на выражения:
1) ¬(A ∧ B) ∨ ¬(A ∨ C) = ¬(1 ∧ 0) ∨ ¬(1 ∨ 1) = 1 ∨ 0 = 1 (ИСТИНА)
2) (A ∧ B) ∨ (¬B ∧ C) = (1 ∧ 0) ∨ (¬0 ∧ 1) = 0 ∨ 1 = 1 (ИСТИНА)
3) (A ∧ B) ∨ ¬C = (1 ∧ 0) ∨ ¬1 = 0 ∨ 0 = 0 (ЛОЖЬ)

**Итоговый ответ:** 1, 1, 0
